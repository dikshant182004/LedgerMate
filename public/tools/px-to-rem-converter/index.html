💡 Tailwind CSS Spacing Cheat Sheet

  • Formula: In Tailwind, 1 spacing unit = 0.25rem = 4px. So p-4 = 16px, p-8 = 32px, p-12 = 48px, and p-16 = 64px.
  • REM vs EM: REM calculates based on the root <html> element, whereas EM calculates relative to the immediate parent container.
