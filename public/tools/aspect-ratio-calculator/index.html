Educational Guide

Simplifying Ratios Using the Greatest Common Divisor (GCD)

An aspect ratio describes the proportional relationship between width and height. To find the simplest integer ratio of a 1920 × 1080 resolution, apply the Euclidean algorithm to find the Greatest Common Divisor (GCD = 120):

Width: 1920 ÷ 120 = 16
Height: 1080 ÷ 120 = 9
Aspect Ratio = 16:9 (Decimal: 1.777... : 1)

Evolution of Cinematic and Display Standards

Display formats have evolved to balance human peripheral vision and cinematic storytelling:

  • 4:3 (1.33:1): The classic Academy ratio and CRT television standard through the late 1990s.
  • 16:9 (1.78:1): The universal high-definition broadcast standard (1080p, 4K UHD, computer monitors).
  • 21:9 (2.33:1 / 2.39:1): Anamorphic widescreen cinema standard; eliminates black bars in movie theaters.

Modern Social Media & Mobile Dimensions

Smartphone vertical orientation inverted traditional media consumption:

• 9:16 (1080 × 1920 px): Fullscreen vertical video (Instagram Reels, TikTok, YouTube Shorts)
• 1:1 (1080 × 1080 px): Classic square Instagram feed post
• 4:5 (1080 × 1350 px): Portrait feed post occupying maximum vertical mobile screen real estate

Modern Responsive CSS: The aspect-ratio Property

Web developers previously relied on the "padding-bottom percentage hack" (e.g. padding-top: 56.25% for 16:9) to prevent layout shifts. Modern CSS natively supports the aspect-ratio property:

.responsive-video {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

Letterboxing vs. Pillarboxing: Geometric Mismatch

When content aspect ratio does not match the display container:

Letterboxing occurs when displaying wider content (e.g. 2.39:1 widescreen) on a narrower screen (16:9), adding horizontal black bars top and bottom. Pillarboxing occurs when displaying narrower 4:3 content on a 16:9 monitor, adding vertical black bars on the left and right.

The Definitive Designer's and Engineer's Guide to Aspect Ratios, Display Resolutions, and Scaling

In visual design, cinematography, and software engineering, understanding the mathematics of aspect ratios is essential. An aspect ratio defines the proportional relationship between an image's horizontal width and vertical height, regardless of physical display scale or pixel density.

1. Calculating Missing Dimensions

To scale an asset proportionally while maintaining aspect ratio:

  • To Find New Height: New Height = (Original Height ÷ Original Width) × New Width
  • To Find New Width: New Width = (Original Width ÷ Original Height) × New Height

Frequently Asked Questions (FAQ)

Expert answers to aspect ratio conversions, video resolutions, and display formats.

What is an aspect ratio?

An aspect ratio is the proportional relationship between the width and height of an image, video, or display screen, written as two numbers separated by a colon (e.g., 16:9) where the first number represents width and the second represents height.

What is the most common aspect ratio for video?

16:9 is the universal standard aspect ratio for modern digital video, televisions, laptops, and YouTube. Common 16:9 resolutions include 1920×1080 (Full HD) and 3840×2160 (4K UHD).

What aspect ratio should I use for Instagram and TikTok?

Use 9:16 (1080×1920 pixels) for vertical video content on TikTok, Instagram Reels, and YouTube Shorts. For Instagram feed images, 4:5 (1080×1350 pixels) is recommended because it takes up the maximum screen real estate.

What is the difference between aspect ratio and resolution?

Resolution defines the exact number of pixels in an image (e.g., 1920×1080). Aspect ratio is the simplified geometric proportion between width and height (16:9). A 1280×720 image and a 3840×2160 image have different resolutions, but both have the exact same 16:9 aspect ratio.

Why do black bars appear on movies playing on my TV?

Most major motion pictures are filmed in ultra-wide anamorphic format (2.39:1), which is significantly wider than standard 16:9 (1.78:1) television screens. Black bars (letterboxing) are added to fit the wider picture without cropping the director's composition.

How does the CSS aspect-ratio property work?

The CSS aspect-ratio property (e.g. aspect-ratio: 16 / 9;) instructs the browser to automatically maintain the specified proportional dimensions whenever one dimension (such as width: 100%) is set, eliminating cumulative layout shifts (CLS).
