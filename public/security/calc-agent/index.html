🛡️ Zero-Knowledge Security Model

API Key Security & Data Privacy

How LedgerMate guarantees that your Google AI Studio API key and private calculations stay confidential.

1. Ephemeral Client-Side Web Crypto Encryption

When you input your Google AI Studio API key, your browser uses the native Web Cryptography API (crypto.subtle) with AES-GCM (256-bit) to encrypt the key in volatile browser memory before placing it in temporary session storage.

Plaintext keys are never attached to HTML element attributes, logged in global window objects, or accessible to third-party scripts.

2. Zero-Database Key Persistence

During query execution, the API key is passed strictly inside encrypted HTTPS request headers to Google's Gemini servers. The Cloudflare Worker never saves your API key into Cloudflare D1 databases, log files, or caching layers.

3. Frequently Asked Questions (FAQ)

Will LedgerMate charge my credit card for calculations?

No! Google AI Studio provides 15 Requests Per Minute (RPM) and 1 Million Tokens Per Minute 100% free of charge without requiring a credit card.

What happens when I sign out or close my tab?

Closing your browser tab or clicking "Sign Out" immediately wipes the in-memory AES key and purges session storage from your device.

Can other users or admins view my API key?

Never. Your key is not persisted to any database or accessible to administrators.
